# Portafolio · Electrónica Analógica 3

Portafolio web de **Juan Camilo Monje Rivas** (Desarrollo técnico y hardware, Equipo 6) en Electrónica Analógica 3, Programa de Ingeniería Electrónica, Universidad Surcolombiana.

Incluye seis proyectos con la PSoC 5LP (CY8CKIT-059): ADC con LDR, concepción de una solución electrónica, póster divulgativo NFC, PMV de sensores DHT11 + YL-38, puente H rediseñado con hojas de datos y el módulo expansor de puente H V2.

**Equipo 6:** Daniel García Trujillo · Juan Camilo Monje Rivas · Horus Samuel Ordoñez Dussán · Juan David Iriarte Trilleras · David Perdomo Cardoso.

Sitio estático (HTML, CSS y JavaScript sin dependencias). Para verlo localmente, abre `index.html`.
